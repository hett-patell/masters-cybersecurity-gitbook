# Documents & deadlines

## What you need to produce

| Item                          | Status     | Notes                                                                                             |
| ----------------------------- | ---------- | ------------------------------------------------------------------------------------------------- |
| **IELTS Academic**            | ✅ Decided  | Book Nov–Dec 2026. Target 7.0, min 6.5. ~₹18,000                                                |
| **Transcripts**               | Needed     | All 8 semester marksheets + consolidated transcript (sealed) from BVM                             |
| **Degree certificate**        | Needed     | BVM will issue after graduation                                                                   |
| **2 × LOR**                   | Needed     | 1 academic (BVM faculty) + 1 professional (Inventyv). Submit NASA Letter of Recognition as supplementary. |
| **SOP / personal statement**  | Needed     | Evidence-led: CVEs, NASA, CERT-In. ~1 page.                                                      |
| **CV**                        | Needed     | 1–2 pages. Include CVE table.                                                                     |
| **Passport**                  | Check      | Validity must exceed course end date                                                              |
| **Application fee**           | Budget     | £0–£75 per university. Budget for ~6 applications.                                                |
| **WES**                       | ❌ Not needed | UK/NZ/Canada universities evaluate internally                                                  |
| **GRE**                       | ❌ Not needed | Waived/optional for cyber MScs                                                                  |
| **ATAS**                      | ✅ Not required | Confirmed: taught cyber MScs have no ATAS requirement (Appendix ATAS 4.1(b) contains no computing codes) ✅ |
