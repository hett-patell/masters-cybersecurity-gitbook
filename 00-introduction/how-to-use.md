# How to read this book

## Confidence markers

Every claim carries a marker:

| Marker           | Meaning                                                          |
| ---------------- | ---------------------------------------------------------------- |
| ✅ VERIFIED       | Fetched from an official source in-session, date given           |
| ⚠️ UNVERIFIED    | Recorded but not independently confirmed                         |
| ❌ KNOWN WRONG    | Was in the vault, proven false, corrected                        |
| 🔍 UNVERIFIABLE  | Source exists but cannot be scraped (JS-walled, auth-gated)      |

## Fee conventions

{% hint style="info" %}
* All fees show the **academic year** they apply to (e.g. "2027/28")
* `NOT FOUND` means the official page wouldn't yield it — never an estimate
* **Net cost** = gross international fee − verified automatic scholarship only
* Competitive awards are shown as upside, never subtracted from net cost
* FX rates used: £1 ≈ CAD 1.79 ≈ NZD 2.1 (declared, auditable)
{% endhint %}

## Scholarship types

| Type               | How                                                   | Budget treatment                         |
| ------------------ | ----------------------------------------------------- | ---------------------------------------- |
| 🤖 **Automatic**   | Assessed from your application — no separate form      | **Bank on it**                           |
| 🎯 **Competitive** | You must apply and be selected                         | **Treat as upside — budget £0**          |
