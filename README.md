# Masters in Cybersecurity — Het Patel

{% hint style="success" %}
**Settlement-first research** for one cybersecurity master's application — **UK · Canada · New Zealand · September 2027.**
{% endhint %}

The goal: decide **where to study** so you can **get a job and stay permanently**. Every fee, deadline, entry bar, scholarship and visa rule was fetched from an official source and dated. Where a page wouldn't yield a number, it says `NOT FOUND` — never a guess.

---

## The one-line verdict

{% hint style="danger" %}
**Cost is not the problem. Settlement is.**

🇬🇧 **UK** — cheapest to study, **hardest to stay**: graduate cyber pay (£25–35k) sits _below_ the Skilled Worker visa bar (£41,700).

🇨🇦 **Canada** — best all-round: 3-year open permit, no salary floor, no sponsor needed.

🇳🇿 **New Zealand** — fastest route to PR: **ICT Security Specialist is Green List Tier 1 → Straight to Residence.** ⚠️ But requires 2× median wage (NZD $70/hr = $145,600/yr).
{% endhint %}
