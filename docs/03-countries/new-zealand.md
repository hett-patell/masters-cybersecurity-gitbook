## The visa chain ✅

```
Study (1.5 yrs) → PSWV (3 years) → land ICT Security Specialist job (accredited employer)
   → Straight to Residence Visa → Permanent Resident after 2 years
```

| Step               | Detail                                                                   | Source                  |
| ------------------ | ------------------------------------------------------------------------ | ----------------------- |
| **Student visa**   | Proof of funds: **NZD $20,000/year** + paid tuition + outward travel ✅  | immigration.govt.nz     |
|                    | Work limit: **25 hours/week** during term ✅ (increased from 20, effective 3 Nov 2025) | INZ U13.15 |
| **PSWV**           | **3 years** for master's graduates ✅                                    | INZ WD3.5(a)(iii)       |
| **Green List Tier 1** | **ICT Security Specialist (ANZSCO 262112) → Straight to Residence** ✅✅ | INZ Appendix 13 Part A |
| **Residence**      | PR after holding Resident Visa for **2 years** (184+ days/yr in NZ) ✅   | INZ RV2.5               |
| **Total to PR**    | **~1–2 years** after landing the role                                    | —                       |

!!! danger
    The vault said NZ proof of funds is NZD $5,000. **That's for the Post-Study Work Visa, not the Student Visa.** The student visa requires **NZD $20,000/year** — 4× what was claimed.


## The Green List advantage ✅✅

This is the **single best-evidenced claim** in the entire vault:

!!! success

### ⚠️ The pay threshold is HIGH

Tier 1 Straight to Residence for **ICT Security Specialist (ANZSCO 262112)** requires a role-specific minimum remuneration:

| | Amount |
|---|---|
| NZ median wage (from 9 Mar 2026) | NZD $35.00/hr ≈ NZD $72,800/yr ✅ |
| **Green List Tier 1 — ICT Security Specialist** | **NZD $72.80/hr ≈ NZD $151,424/yr** |
| Contract for services rate | NZD $109.20/hr + 10 yrs experience |

!!! warning
    That's a **very high bar for a fresh graduate.** Realistically: graduate → junior role → 1–2 years experience → qualifying role → apply.

## Government/defence roles ✅

!!! success
    The vault said government/defence cyber roles are "citizenship-gated." **Partially wrong.**

    * **NZ Police and NZDF** accept **Permanent Residents** (not just citizens) ✅
    * Only **GCSB/NZSIS** intelligence roles with "NZ Eyes Only" caveats are strictly citizen-only
    * Standard security clearances (Confidential, Secret, Top Secret) can be granted to NZ Resident Visa holders
