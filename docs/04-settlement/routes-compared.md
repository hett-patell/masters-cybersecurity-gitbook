# The three migration routes compared

=== "🇬🇧 UK — slowest, and slowing"

    ```
    Study (1 yr) → Graduate visa (18 months) → find a sponsor paying £33,400–41,700
       → Skilled Worker → 5 years → ILR → citizenship after 1 year
    ```

    | Step | Detail |
    |---|---|
    | Graduate visa | **18 months** (from 1 Jan 2027) ✅ |
    | Next step | **Skilled Worker — requires a licensed sponsor employer** |
    | Salary floor | **£41,700** standard · **£33,400** new entrant (under 26) ✅ |
    | Settlement | **5 continuous years** on Skilled Worker. **Student time does NOT count.** ✅ |
    | **Realistic total** | **~6.5–7+ years** |

    !!! danger
        UK graduate cyber pay (£25–35k) sits **below** the visa bar. You can get the job and still be forced home.

=== "🇨🇦 Canada — balanced"

    ```
    Study (1–2 yrs) → PGWP (3 years, OPEN) → 1 yr Canadian skilled work
       → Express Entry / Canadian Experience Class → PR
    ```

    | Step | Detail |
    |---|---|
    | PGWP | **3 years**, **open** — no employer sponsorship needed ✅ |
    | Salary floor | **None** ✅ |
    | Key rule | Master's degree is **exempt** from PGWP field-of-study restrictions ✅ |
    | Route to PR | **Express Entry** — CRS points competition |
    | **Realistic total** | **~2–3 years** |

    **The advantage:** take _any_ job while building experience. No permission bottleneck.

    **The risk:** CRS is competitive, and Canada has been cutting immigration targets.

=== "🇳🇿 New Zealand — fastest"

    ```
    Study (1.5 yrs) → PSWV (3 years) → land ICT Security Specialist job
       → Straight to Residence Visa → PR after 2 years
    ```

    | Step | Detail |
    |---|---|
    | PSWV | **3 years** ✅ |
    | Green List Tier 1 | **ICT Security Specialist** → **Straight to Residence** ✅✅ |
    | Salary floor | **ICT Security Specialist: NZD $72.80/hr ($151,424/yr)** |
    | **Realistic total** | **~1–2 years** (after landing qualifying role) |

    **The advantage:** no points race, no waiting — apply the moment you hold the job offer.

    **The risk:** smallest job market, senior-skewed, and that salary threshold is high.
