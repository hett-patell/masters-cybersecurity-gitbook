## NIRF — participant, NOT ranked ✅

NIRF publishes **two different lists**:

| List              | What it contains                              | BVM present? |
| ----------------- | --------------------------------------------- | ------------ |
| **Ranked**        | ~300 institutions with a score and rank        | ❌ **No**    |
| **Participated**  | ~1,464 institutions that submitted data        | ✅ Yes       |

BVM's own NIRF PDFs are headed _"Submitted Institute Data"_ with reference `IR-E-C-347`. That's a **submission ID, not a rank**.

{% hint style="danger" %}
Aggregator sites claiming "BVM NIRF rank 250" are quoting **IIRF**, a completely different body. Never cite it as NIRF.
{% endhint %}

### Why this matters

Several UK universities tier Indian applicants by institution:

| University       | How it tiers                                                                  |
| ---------------- | ----------------------------------------------------------------------------- |
| **Loughborough** | Different bar for institutions "on the NIRF"                                  |
| **UWE Bristol**  | NOOSR Section 1 vs Section 2                                                  |
| **Lancaster**    | "varies by the ranking of the awarding University"                            |
| **Aberdeen**     | "for State and Central Universities we look for 60%" — BVM is neither         |
| **Coventry**     | 55% route only for a listed set (Delhi, Mumbai, Anna…) — BVM isn't on it      |

{% hint style="danger" %}
**This is the single biggest risk in the plan.** Because BVM is autonomous, NAAC-'A', NIRF-participant but **not** a central university, IIT, NIT, or Institute of National Importance, its placement is ambiguous. **Get your band confirmed in writing, per university.**
{% endhint %}
